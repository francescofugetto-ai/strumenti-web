# Strumenti

**https://francescofugetto-ai.github.io/strumenti-web/**

La vetrina dei tool pubblicati: una pagina sola che li elenca, ciascuno col suo
indirizzo. La genera `scripts/vetrina.py` di un repository privato dal registro
`vetrina.json`: **non modificare i file qui**, la pubblicazione successiva li
sovrascrive.

Nessun tool rimanda a questa pagina, per scelta: chi riceve l'indirizzo di un
solo strumento vede quello e nient'altro.
